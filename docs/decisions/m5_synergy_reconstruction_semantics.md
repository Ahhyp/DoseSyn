# M5 协同评价语义审计：X/X0 与 Bliss / HSA / Loewe / ZIP 的兼容性

**结论（先行）**：在 O'Neil 数据当前可验证的信息范围内，`X/X0` 不能无假设地转换为任何标准协同分数。
本仓库 **不输出** Bliss、HSA、Loewe、ZIP 的“标准协同值”；它们的状态统一为
`NOT_VALIDATED`。M5 只拟合观测到的 `X/X0` 曲面，不把任何派生量称为协同分数。

## 1. 数据侧事实

| 事实 | 数值/说明 |
| --- | --- |
| 标签 | `X/X0`（相对 DMSO 的存活/增殖比例，source 定义：0=完全抑制，1=无效应） |
| 范围 | M1 双药点 `X/X0 ∈ [0, 2.34333]`；25,247 点 >1，7 点 >2 |
| 零剂量 | 原始数据没有真正的 vehicle/零剂量锚点；M1 全部浓度 >0 |
| 剂量网格 | 每个矩阵 4×4，仅 4 个浓度/药物；不同矩阵网格不同 |
| 重复 | 每个点最多 4 个技术重复；缺失 6,018 个值 |
| 批次 | 315 个条件跨批次，210 个网格不同 |

这些事实直接决定了标准协同模型的可用性：标准方法需要“效应”定义、单药剂量-效应曲线、
以及（对 Loewe/ZIP）在组合浓度处可插值的单药响应；本数据没有零剂量锚点，且组合浓度
未必落在单药测量网格上。

## 2. 标准方法的数学要求与差距

设 `E` 为抑制效应，常用 `E = 1 - X/X0`。当 `X/X0 > 1` 时 `E < 0`（增殖），
而 Bliss/HSA/Loewe/ZIP 的经典推导假设 `E ∈ [0,1]` 且单药曲线单调。

### 2.1 Bliss Independence

`E_Bliss = E_A + E_B - E_A·E_B`。

- 需要同一细胞系上药物 A、B 在**组合所用剂量**处的单药效应 `E_A(x)`、`E_B(y)`。
- 我们的单药表是 8 点曲线，组合剂量（尤其是 µM 级高剂量）不一定被单药表覆盖；
  需要插值/外推，且外推在 `X/X0 > 1` 区域没有约束。
- 若直接把 `E` 截断到 `[0,1]`，会改变数据分布并把增殖点当作“零效应”，属于未经验证的假设。

**状态：NOT_VALIDATED。**

### 2.2 HSA（Highest Single Agent）

`E_HSA = max(E_A, E_B)`，协同为 `E_AB - E_HSA > 0`。

- 同样需要组合剂量处的单药效应。
- 对 `E<0` 或非单调单药曲线，`max` 的生物学解释不成立。

**状态：NOT_VALIDATED。**

### 2.3 Loewe Additivity

基于“剂量等效”：
`x/X_A + y/Y_A = 1`（或浓度平移形式），需要单药剂量-效应曲线可逆、单调。

- 需要为每个 `(cell, drug)` 拟合可逆曲线（如 Hill），再在组合剂量处求等效剂量。
- 本数据每药仅 4 个组合浓度、单药 8 点且存在 >1 区域；没有零剂量锚点，
  Hill 下平台/上平台不可识别。
- 不同批次、不同网格使曲线拟合本身带批次/网格假设。

**状态：NOT_VALIDATED。**

### 2.4 ZIP（Zero Interaction Potency）

ZIP 以“零交互”下的剂量-效应曲面为基线，需要拟合每条单药曲线的参数
（通常 Hill 参数），再构造 `E_ZIP(x,y)`。

- 与 Loewe 相同的数据要求，且对曲线参数估计非常敏感。
- 在 `X/X0` 有 0 下限（213 个精确 0，由四舍五入产生）与 >1 区域时，
  参数估计需要额外截断/链接函数假设，未经验证不能称为标准 ZIP。

**状态：NOT_VALIDATED。**

## 3. 本仓库的处理

1. M5 的组合标签始终是原始 `X/X0`；不生成 Bliss/HSA/Loewe/ZIP 标签。
2. 不把 `1 - X/X0` 或任何裁剪后的量写进训练目标。
3. 报告中的 `E_swap`、`E_boundary`、`R_smooth` 是**模型自洽性诊断**，不是协同分数。
4. 若 M6 之后需要协同监督，必须先：
   - 明确 `E` 的定义域与 >1 区域的处理；
   - 用单药数据拟合曲线并做留出验证；
   - 对零剂量/外推做敏感性分析；
   - 在报告中标注方法版本与验证范围，未通过验证前继续标 `NOT_VALIDATED`。
